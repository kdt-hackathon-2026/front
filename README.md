## 🌿 브랜치 전략

- `main`: 최종 배포 및 안정 버전
- `develop`: 기능 통합 브랜치
- `feat/{이슈번호}-{기능명}`: 기능 개발
- `fix/{이슈번호}-{수정명}`: 버그 수정
- 이슈 브랜치는 `develop`에서 생성하고, 작업 완료 후 `develop`을 대상으로 PR을 생성합니다.
- 배포 준비가 완료되면 `develop → main` PR을 생성합니다.
